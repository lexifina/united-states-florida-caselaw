# Hobbs v. State

## Majority (PER CURIAM.)

PER CURIAM.
We initially accepted for review the decision of the First District Court of Appeal in Hobbs v. State, 820 So.2d 347 (Fla. 1st DCA 2002), which certified conflict with Whitson v. State, 791 So.2d 544 (Fla. 2d DCA 2001). Upon further consideration, we find that review was improvidently granted. Accordingly, this review proceeding is dismissed.
It is so ordered.
ANSTEAD, C.J., and WELLS, PARIENTE, LEWIS, CANTERO, and BELL, JJ., concur.
QUINCE, J., dissents.
