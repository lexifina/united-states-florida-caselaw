# State v. McCray

## Majority (McDONALD, Justice.)

McDONALD, Justice.
We approve the district court’s dismissing the state’s appeal as untimely filed, State v. McCray, 544 So.2d 313 (Fla. 2d DCA 1989), because we have decided this issue in Fox v. District Court of Appeal, 553 So.2d 161 (Fla.1989), and State v. Hieber, 553 So.2d 704 (Fla.1989), adversely to the state.
It is so ordered.
EHRLICH, C.J., and OVERTON, SHAW, BARKETT, GRIMES and ' KOGAN, JJ., concur.
