# State v. Clark

## Majority (PER CURIAM.)

PER CURIAM.
We initially accepted for review the decision of the Fourth District Court of Appeal in State v. Clark, 770 So.2d 237 (Fla. 4th DCA 2000), which certified conflict with the Second District’s decision in State v. Barnes, 753 So.2d 605 (Fla. 2d DCA 2000). Upon further consideration, we find that review was improvidently granted. Accordingly, this review proceeding is dismissed.
It is so ordered.
WELLS, C.J., and SHAW, HARDING, ANSTEAD, PARIENTE, LEWIS, and QUINCE, JJ., concur,
