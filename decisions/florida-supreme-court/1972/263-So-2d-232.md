# Wheeler v. State

## Majority

The motion for summary reversal is hereby granted and the judgment and sentence below is hereby reversed and this cause remanded to the Felony Court of Record, Volusia County, for further proceedings consistent with the opinion of this Court in State v. Barquet, 262 So.2d 431, opinion filed February 14, 1972.
