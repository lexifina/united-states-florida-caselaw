# State v. Kronowit

## Majority (PER CURIAM.)

PER CURIAM.
The order of the trial court, finding section 893.03(l)(c), Florida Statutes (1978 Supp.), to be unconstitutional, is reversed on the basis of this Court’s recent ruling in State v. Cheatham, 376 So.2d 1167 (Fla.1979). This case is remanded for further proceedings consistent with that opinion.
It is so ordered.
ENGLAND, C. J., and BOYD, OYER-TON, SUNDBERG, ALDERMAN and MCDONALD, JJ., concur.
ADKINS, J., dissents.
