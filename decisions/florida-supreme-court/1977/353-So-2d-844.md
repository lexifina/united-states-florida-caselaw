# Kelly v. State

## Majority (PER CURIAM.)

PER CURIAM.
The petition for certiorari was denied.
We have considered the petition for cer-tiorari as an application for writ of habeas corpus. It states no basis for granting relief by habeas corpus, hence such application is also denied.
It is so ordered.
BOYD, Acting C. J., ENGLAND, SUND-BERG and HATCHETT, JJ., and DREW (Retired), J., concur.
