# Ford v. State

## Majority (PER CURIAM.)

PER CURIAM.
We approve Ford v. State, 586 So.2d 511 (Fla. 1st DCA 1991), on the authority of Burdick v. State, 594 So.2d 267 (Fla.1992). As in Burdick, we answer the certified question in the affirmative.
It is so ordered.
