# State v. Pierre

## Majority (PER CURIAM.)

PER CURIAM.
We initially accepted review of the opinion in Pierre v. State, 732 So.2d 376 (Fla. 2d DCA 1999), based on alleged express and direct conflict with the opinion in State v. Dilyerd, 467 So.2d 301 (Fla.1985). Upon further consideration, we find that jurisdiction was improvidently granted in this case. Accordingly, we hereby dismiss review of this cause.
It is so ordered.
HARDING, C.J., and SHAW, WELLS, ANSTEAD, PARIENTE, LEWIS and QUINCE, JJ., concur.
