# Rivers v. State

## Majority (PER CURIAM.)

PER CURIAM.
We review Rivers v. State, 601 So.2d 561 (Fla. 2d DCA 1992), in which the court affirmed a sentence based on State v. Tripp, 591 So.2d 1055 (Fla. 2d DCA 1991), quashed, 622 So.2d 941 (Fla.1993). In light of this Court’s decision in Tripp, we quash the decision below and remand for proceedings consistent with Tripp..
It is so ordered.
BARKETT, C.J., and OVERTON, McDonald, shaw, grimes, kogan and HARDING, JJ., concur.
