# Jeralds v. State

## Majority (PER CURIAM.)

PER CURIAM.
We granted review of Jeralds v. State, 603 So.2d 643 (Fla. 5th DCA 1992), but now find that any conflict has been dispelled by Munoz v. State, 629 So.2d 90 (Fla.1993). Therefore, we dismiss the petition for review.
It is so ordered.
BARKETT, C.J., and OVERTON, McDonald, shaw, grimes, kogan and HARDING, JJ., concur.
