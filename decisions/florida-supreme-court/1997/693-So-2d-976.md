# State v. Rodriguez

## Majority (SHAW, Justice.)

SHAW, Justice.
We have for review Rodriguez v. State, 683 So.2d 162 (Fla. 4th DCA 1996), based on conflict with State v. Wilson, 686 So.2d 569 (Fla.1996). We have jurisdiction. Art. V, § 3(b)(3), Fla. Const. We quash Rodriguez.
It is so ordered.
KOGAN, C.J., and OVERTON, GRIMES, HARDING, WELLS and ANSTEAD, JJ., concur.
