# Doctor v. State

## Majority (SHAW, Justice.)

SHAW, Justice.
We have for review Doctor v. State, 677 So.2d 1372 (Fla. 3d DCA 1996), based on conflict with Wilson v. State, 668 So.2d 998 (Fla. 4th DCA 1995). We have jurisdiction. Art. V, § 3(b)(3), Fla. Const. We have since quashed Wilson. See State v. Wilson, 686 So.2d 569 (Fla.1996). We approve the result in Doctor on this issue.
It is so ordered.
KOGAN, C.J., and OVERTON, GRIMES, HARDING, WELLS and ANSTEAD, JJ., concur.
