# State v. Childre

## Majority (PER CURIAM:)

PER CURIAM:
The state appeals from an order granting a new trial in a criminal case. We find no abuse of discretion and the order is affirmed.
CHAPMAN, C.J., TERRELL, BUFORD and ADAMS, JJ., concur.
