# State v. Cifuentes

## Majority (SHAW, Justice.)

SHAW, Justice.
We have for review Cifuentes v. State, 674 So.2d 743 (Fla. 4th DCA 1996), based on conflict with State v. Wilson, 686 So.2d 569 (Fla.1996). We have jurisdiction. Art. V, § 3(b)(3), Fla. Const. We quash Cifuentes.
It is so ordered.
OVERTON, GRIMES, HARDING, WELLS and ANSTEAD, JJ., concur.
